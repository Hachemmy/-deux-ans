# Two Years With You ♥

Un site surprise pour célébrer deux ans d'amour : enveloppe animée, lettre, souvenirs, musique et un petit mot envoyé par EmailJS.

## Structure

- `index.html` — page principale
- `style.css` — styles et animations
- `script.js` — interactions et envoi EmailJS
- `assets/` — photos, musique et illustrations

## Utilisation

Ouvre `index.html` dans un navigateur et entre le code secret pour découvrir la surprise.
